# Student Record Manager CLI

A simple command-line application built with Python to manage student records.

## Features

- Add new student records
- View all students
- Search students by ID
- Update existing student details
- Delete student records with confirmation
- Validate user input
- Save and load records using JSON
- Keep records available after restarting the program

## Requirements

- Python 3 installed

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the application:

   ```bash
   python main.py
   ```

4. Follow the on-screen menu.

## Data Storage

Student records are stored locally in a `students.json` file, which is created when the application saves records.

## Technologies Used

- Python
- JSON
- Command-line interface

## Concepts Practiced

Functions, loops, conditionals, lists, dictionaries, input validation, file handling, JSON serialization, and exception handling.
